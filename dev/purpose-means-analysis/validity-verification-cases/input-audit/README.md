## 状态与用途分别判断

| 状态 | 数量 | 含义 |
|---|---:|---|
| ready_text | 118 | 能分离出原文任务或情境文本。不是118道独立盲题。 |
| insufficient_statement | 82 | 缺少完整任务，或只有方案、类比、回指，不能根据答案反造原题。 |
| source_conflict | 4 | T01、T35、T36、T55，原书目标、介质或单位有未澄清问题，默认不选入完整盲试。 |
| needs_figure | 1 | U3-017须带原结构图16(a)，不能只给OCR文本。 |

118条ready_text中，75条为generation，可作为生成任务候选。
这75条包含已试10题，尚未试的常规生成候选为65条。
其余为28条任务重构、6条预测、4条科学史重构、2条给定方案分析及3条概念讨论。
这些用途不可混算为“在未见方案时生成原书答案”。
状态由一次逐条资料审核和必要定点核字产生，不表示所有书页都逐字核过PDF。本次定点核29个物理页，
另复用已有的T07精度、T26物质名和温度核字记录。
同书条目也不一定相互独立，不据此推算方法完备性或成功率。

## 发现的问题

- 摘要有实质删减，例如T34低速喷涂的控制和覆盖优势、T49全电压绝缘要求，
  以及T61真溶液的分子、原子、离子解释。
- 有语气变化，例如T51原文说传感器“不好”“更不好”，旧摘要强化为禁止。
- 有question_refs实际指向解法回提，不能按原索引范围整段送给盲解者。
  这属于未来输入的风险，不证明已试Agent读了这些段落。
- 有目标被摘要改写，例如T01根据后文被概括为防止液氧气化，
  PDF却确认原题确写“氧……不被氧化”。不静默选择一种解释。
- 有原书直接给方案再问其原理的题，如T16；有预测题、科学史及专利前序。
  保留原任务类型，不将其全部改写为独立发明题。

## 后续输入的具体变化

公开questions.md继续作导航，**不再直接充当试解输入**。
原文题干包只含经定位的原句、必要上下文及原题提示，使用中性编号标题。
后文明示补充条件另有增补版本，不悄悄拼入首次题干，也不从解法推导新条件。

```bash
python3 scripts/prepare_case_input.py T13 batches/round-02/T13/question.md
```

这里只演示命令，尚未启动round-02。
脚本默认只接收ready_text且evaluation_mode为generation的条目，
拒绝覆盖既有文件。其他研究用途须显式指定对应mode。
有later_constraint时，可选`--include-later-constraints`，并记录为增补输入版本。

完整私有包可由本人持有的OCR及公开片段定位、字符范围重新生成。
所有OCR更正都列出替换前后和已核PDF页码，原OCR文件不改。
大部分原书异常措辞保持原字，不以常识润色成新的“原题”。

已试10题的question与冻结稿全部保持原样，本轮没有重试。
A/B标签仍描述当时实际输入下的候选覆盖，不能据静态核对保证补全题干后结果不变。

这些是输入可用性分类，不是CCA/PMA适用边界的结论。
预测、重构等用途仍可另行研究，不与常规生成盲试混算。
