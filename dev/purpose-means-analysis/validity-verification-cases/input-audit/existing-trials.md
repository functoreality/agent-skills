# 已试10题：实际输入与原文的差异

冻结输入及候选均未修改，本轮没有重试。
A/B仍是当时实际输入下的覆盖事实，不是原题与摘要等价性的证明。
不能仅凭删去信息看似冗余，或Agent自行补想了某条件，就断言没有影响。

| 案例 | 实际输入核对 | 对既有结论的限制 |
|---|---|---|
| T04 | 原试点接近逐字转录，未发现实质题干信息删减。 | 现有核心命中事实保留，仍有原已记录的熟悉度及工程限制。 |

| T61 | 保留真溶液一词，删去括注的分子、原子、离子存在形式。该括注是原题信息，不是后文答案。 | 原输入下A事实保留，不能把本次与含原题完整提示的试解视作同一实验条件。 |

索引中的statement、question_refs和真正发给Agent的question.md分别核对，
不能把“索引回指可能含解法”误说成“旧试解已经读答”。
同理，T07实际题干已有免费条件，不能只看索引摘要就声称试点漏了免费。

若重试补全版本，应另建输入、用新的解题上下文及冻结记录，
把差别标明为输入版本变化，不把重试收益归给未变化的Skill。
