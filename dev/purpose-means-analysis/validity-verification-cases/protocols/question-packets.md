# 题干包规则

本规则用于后续选题与资料准备，不修改CCA/PMA Skill。
[全量审核](../input-audit/README.md)覆盖205条，旧摘要仅作导航。

## 准备与检查

1. 先看审核状态和evaluation_mode，不按题号或摘要长度推断可盲解。
   默认生成任务只用ready_text且mode=generation的记录。
2. 用prepare_case_input.py按原文位置及字符边界生成题干。
   对照原题、上下文、全部跨页、数值、限制、失败尝试及原题提示，选题前再查边界。
3. 使用中性编号标题，不发旧关键词、问题归因、案例复盘或可能泄答的标题。
4. 首次题干及原有上下文/提示是基础版本。
   后文明示的任务重述或补充条件另存增补版本，选择后在轮次manifest中写明。
   解法步骤、由答案推出的前提及实验中的额外提示均不因此成为原题条件。
5. 原题若要求识别TRIZ技法、解释已给装置，应按原任务类型记录。
   用户指定本研究使用CCA/PMA，方法使用服从用户要求，
   不把原书练习程序当作偷偷引入另一套解题工具的授权。
   原文中的功能、资源及“不引进庞杂设备”等技术约束仍须保留。
6. 缺独立任务的不自编题，关键原书矛盾不猜改，缺图不以文字想象代替。
   重构任务或给定方案分析可另做研究，但不混算成原始盲题命中。
7. 已核OCR错误用显式替换及PDF页码记录，原文、图像只放_private。
8. 来源准备者读过答案，不能复用为对应题的盲解者。

## 运行与复核

每轮固定具体题干、是否含后文补充、任务类型、来源包哈希和Skill版本。
仍先CCA/PMA、再RA增量、各自冻结后揭答。
未来使用batch-solver-v2，旧协议及既有冻结输入不覆盖。
题干更正若发生在试解之后，标记旧结果适用的输入版本，不能沿用旧结果冒充新盲测。
是否重试旧题与如何设计独立试验另由用户决定。
