# 候选观察台账

本目录保存本项目尚待验证的学习，不作为解题指令输入。
实际Skill保持独立，只有用户批准的通用改动才进入Skill。

[观察记录](observations.json)保存事实来源、归因置信度、支持与反证、后续动作。
详细证据保留在原案例或复盘中，表内相似观察只是候选关联，不自动证明同因。
状态：collecting（收集）、ready_for_discussion（待讨论）、adopted（已采纳）、
revised（已修订）、withdrawn（已撤回）。置信度单列，不以次数自动决定状态。

T07-H1/H2目前各只有T07一题的后验支持，维持collecting。
跨域推演属于思想检验，不计作独立试解。本轮新题不启用这两项指令。
规则的升级、版本记录和回归处理见[迭代计划](../planning/plan-v2.md)。

每轮汇总可提出新增、改写、强化、弱化、限定或删除规则，也可不推荐改动。
公开台账只保留必要摘要和相对引用，完整原书及图像留在私有目录。
