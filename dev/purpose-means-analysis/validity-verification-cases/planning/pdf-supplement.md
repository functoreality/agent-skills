# 原书 PDF 补充核验

用户在三题试点交付后提供原书PDF，允许按必要性使用子Agent补OCR及图示。
该补充不是正式全量分析批准，原有审核停止点保持。

## 选择范围

- T07图2、图3与原题，可能影响几何重建与报告中“缺图”限制。
- T04及T31的原题和答案，只复核现有试点引用及重要条件。
- T26温度、物质名及T27术语，只关闭明显影响后续试解的OCR疑点。
- Page137的回提编号，区分OCR误读与原书错引。
- 课题59到61之间的页段，区分OCR漏题与原书编号缺口。

不重做全书OCR，不重新试解其他案例，不改Skill。
两位资料核验Agent分工看图，优先低分辨率，仅对不清的局部提高分辨率。
原始PDF不复制进仓库，只记录指纹并保存少量关键页/局部作为证据。

## 证据与修订规则

冻结的题干、答案前候选、统一解题协议及原始OCR不改。
修订限于揭答后对照、试点汇总、材料索引与补充核验说明。
原先按当时材料写出的检查记录保持历史属性，新增PDF复核记录说明变化。
若PDF暴露试点题干的重要变化，标记可比性限制，不能回填后再算独立命中。

先看两位核验者报告，再由主Agent依据证据决定要修改哪些判断。
涉及读图才能裁决的争点，主Agent必要时只看相关局部。
