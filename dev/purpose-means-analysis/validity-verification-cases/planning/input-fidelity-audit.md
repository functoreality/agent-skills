# 全量题干保真复核计划

用户发现题目相对OCR压缩，要求覆盖全部205条，包括未来待试题。
本轮先做输入完整性与盲试边界审核，不启动下一批解题或修改Skill。

1. 六组资料审核覆盖205条，每条由一个主审核者负责，必要时跨段回查。
2. 逐项记录信息删减、额外解释、解法泄漏、上下文/图示/OCR依赖。
   原文片段私有保存，公开保留状态、差异与定位，不发布完整书页或整章。
3. 合并并校验205条覆盖、原文片段与来源一致、状态和关键疑点。
   对影响原题理解的必要PDF页作定点补查，无法解决的明确留待处理。
4. 建立私有原文题干包，未来只从合格包选题，公开摘要只作导航。
   摘要不再直接作为盲解输入。标准题干也不能夹带答案段。
5. 回看已试10题：冻结输入不改，报告信息差及对原结论的限制。
   不凭静态复核声称无影响，也不把输入问题归因为Skill缺陷。
6. 完成检查与Git保存，交付总览、逐条状态及既有结果影响，停止等待用户。

本轮审核者读过答案，不能随后复用为对应题目的盲解者。
是否重试受影响旧题由后续单独决定，不能改题干后沿用旧试解作新证据。
