# CCA / PMA 案例检验计划

## 目标与当前停止点

检验因果链分析（CCA）与目的手段分析（PMA）在书中案例上的解题能力，
必要时单独记录资源分析（RA）的贡献。
本轮执行计划、全书题解索引和约 3 题试分析。
完成试点后等待用户审核，收到同意后才开展全量分析与最终汇总。
本任务不直接编辑两个 Skill。

## 评估口径

- A：在接收参考答案前，冻结的具体候选已覆盖原书核心机制。
  仅列“改变材料”“使用物理效应”等宽泛方向不计命中。
- B：未预先命中，但看答案后能给出有效的推理路径。
  必须保留原路径，逐项记下改了哪个节点、展开轴、优先级、
  约束理解或知识前提，再分析是否值得补充 Skill。
- C：当前仍不能构造有解释力的路径，作为重点失败候选。
  区分方法边界、知识缺口、执行偏离和预算不足。
  单次未解出不证明方法不适用。
- U：答案缺失、题干不完整或关键图示不可用，暂不可判。
- A 附加标记：既知答案/疑似记忆命中时记 A-memory，
  仅说明本次候选覆盖，不能作为独立推导证据。
- 解出合理替代方案与复现原书解法分别记录。
  书中解法是否满足题干约束也独立核对，不把参考答案当作绝对真理。

开放方法无法凭有限题集证明数学意义上的完备性。
本轮提供的是案例覆盖、生成证据、失败候选和边界假说。

## 执行阶段

1. 阅读 prompt.txt、两个 Skill 及相关参考，确认仓库与源文档。
   写计划、共享解题协议与需求核对记录。
   按 Task Final Review 完整重读 prompt.txt，核对计划覆盖。
2. 三个提取 Agent 各通读一个原文文件，建立编号题与无编号实例索引。
   主 Agent 合并重复项，跨页跨文件配对答案，生成独立题目表与解答表，
   保留原文页码、行号和可点击链接，登记 OCR 与图示不确定性。
   机械核验编号、引用、去重及题解配对，不确定项显式保留。
3. 选择约 3 道不同任务形态的题，优先覆盖 CCA、PMA 和方法衔接/资源。
   每题一个全新上下文的 Agent，只发题干、Skill 和统一协议。
   先冻结 before-answer.md 并记录哈希，再发答案，写 comparison.md。
   按 Task Final Review 复核本轮需求、引用、分类和前后差异。
   生成简短试点入口，暂停等用户审核。
4. 用户明确同意后：维护全量任务队列，独立解题尽量用满可用并发额度。
   不允许解题 Agent 接触题解表或其他题答案，不重复分析试点已覆盖项。
   所有正式任务沿用冻结后揭答流程，失败与不确定项不得静默跳过。
5. 汇总两个短主文档：按案例组织、按方法组织。
   案例文档突出 B/C/U 并链接详细报告。
   方法文档区分特别适用、可用但欠佳、边界候选，以及具体补充建议。
   每项建议追溯到案例、实际调整、既有规则和证据强度，
   不承诺补充后必然解出所有题目。
   依 Task Final Review 完成需求复核、事实/推理/引用与产物检查。

## 方法使用与偏差控制

新功能或替换整系统用 PMA，现有系统缺点用 CCA。
PMA 候选出现缺点时转 CCA，CCA 干预点需要新功能时转局部 PMA。
RA 作为可选补充，不能把其他 TRIZ 工具偷偷计作 CCA/PMA 自身能力。
完整方法路由、节点规范和揭答协议见 ../protocols/solver.md。
此次按用户授权简化分析深度，省略两个 Skill 的常规子 Agent 审核，
不省略关键推理链、答案前后区分和必要自查。

主 Agent 和提取 Agent 可接触答案，但不承担盲解。
解题 Agent 使用无历史上下文，先自报是否熟悉题目。
文件隔离是协议约束而非操作系统强隔离，模型预训练记忆无法消除。
统一采用适度预算，实际节点数、候选数和暂缓分支留痕。
试点只检验流程与初步模式，不用 3 题估计全书成功率。

## 文件与 Git

- prompt.txt：用户原始需求，保留原文。
- planning/：执行计划和阶段状态。
- protocols/：提取、解题、揭答共用协议。
- inventory/：机器可读清单、题目索引和答案索引。
- sources/：源文件及 Skill 版本指纹，必要的试点题干与答案包。
- pilot/<id>/：每题答案前候选与答案后对比。
- reviews/：计划核对、阶段核验和交付证据。
- scripts/：可复用合并/检查工具。

只提交本任务文件，不携带仓库其他修改。
按计划与协议、索引、试点拆分 commit。
提交前缀统一 `purpose-means-analysis/validation:`，
正文标明同时检验 CCA。Git 元数据若受沙箱限制，通过授权范围的提权执行。
