# T31 合金腐蚀试验容器

在坚固、气密的金属容器里放置 30 到 40 块不同合金，
容器里灌满侵蚀性液体。试验的目的是弄清侵蚀性液体
在高温以及高压条件下对合金表面的作用。
遗憾的是侵蚀性液体同时也作用于容器壁，
因此容器壁需要用贵重金属制作，造价太高。怎么办？
