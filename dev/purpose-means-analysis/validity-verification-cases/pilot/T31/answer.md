# T31 原书答案摘要

公开版仅保留题答所需的核心摘要和短摘录。
试点最初归档的较长揭答片段在本地私有输入中，

让待测合金本身形成杯状空腔，将侵蚀性液体装入其中。
这样液体接触受测合金表面，由合金自身提供接液边界，
而不是让原外容器壁直接接触液体。

必要短摘录：

> 合金块应该是“杯”（空心的合金块）

原书还把这一思路表述为液体空间分布的改变。
高温、高压、气密与测试代表性如何完整实现，
需要另行核查，见[对照报告](comparison.md)。
