# 方法层面的试点观察

这是三题试点的初步诊断，不是全书适用边界或最终 Skill 修改方案。
后续已补[原书PDF核验](../reviews/pdf-supplement-review.md)，三题分类及方法诊断不变。
两个 Skill 未被编辑，证据不足以证明某项补充能保证生成所有原书答案。

## 当前证据支持什么

CCA 能把已有缺点转成可干预的机制或必要条件，
PMA 能组织新功能及替代结构的搜索，二者可以在局部衔接。
T04、T31在本次揭答前已提出对应的核心机制，也能进入这样的结构。
它们涉及RA，并自报读题时已有相近解法联想。
工具日志确认未提前读取本次答案，但不能仅凭这些记录把联想完全归功于Skill。
这属于方法贡献的归因限制，不应误写为“答案前没有生成”或“已证实记忆污染”。
详见[工作流核对](../reviews/workflow-audit.md)。

**T07 是一次真实的答案前未命中。**
揭答后能构造有理由的路径，说明该解法目前并未显示为方法结构之外的反例。
但能容纳不等于会生成，事后的路径也不能追认成先验推导。
本轮没有足以确认“CCA + PMA + RA 仍无法解释”的 C 类实例。

## 已有规则、执行遗漏与可补充提示

下表是初步观察。后续[T07复盘示范](../retrospectives/T07/README.md)进一步检查了
“原则已存在”是否仍需要具体判断问句和触发策略，
不以“先修执行”作为排除Skill改进的结论。候选补丁尚未合入。

| 观察 | 既有覆盖与本轮事实 | 暂定处理 |
|---|---|---|
| 把中间物理状态当成最终缺点 | CCA 步骤1–2已要求识别本质初始缺点。T07却停在绳长大于垂直距离，遗漏读数映射。 | **先修执行。** 保留物理状态也可通过重建估计模型解决真实误差。 |
| 测量方向很宽，却过早固定读数方式 | PMA 3.3及展开范式第5节已有观测信号与测量机制入口。T07未探索水下量向水面可见量的编码。 | 可试“待求量、可见量、约束关系、剩余自由度”的执行提示，需另题验证。 |
| 发现扰动后主要追求抑制它 | T07将绳倾斜视为必须消除，未尝试增加观测后反演。 | 可并列尝试“抑制扰动”和“保留扰动、补足模型”。这是有条件的启发，非每题必做。 |
| 材料替换后遗漏原工作体的一项作用 | PMA已有 And 完备性与反向回放。T04 S6未写冻结磨料，后来才补。 | 先落实被替换对象的必要作用回放，不能直接诊断为缺少节点类型。 |
| 受作用对象可以兼任所需结构 | T31的合金杯让试样兼作接液边界。PMA对象结构选择已有入口，RA使该角色显式化。 | 可保留为弱证据启发，不据一次可能记忆命中固化普遍规则。 |

以上是“具体发生了什么 → 对应既有要求 → 可能的提示”的链条。
执行遗漏、模型知识、搜索预算、Skill 指令不足须分别归因，
不能把每次漏解都转成一条新增规则。
这些提示尚未经陌生题的前瞻试验，不能视作已经验证有效的 Skill 改动。

## 资源分析的贡献与取证边界

- T04：冰的联想早于显式 RA，RA主要整理角色，无法证明独立发现贡献。
- T07：RA产生了水波传播反演的新候选，但没有命中原书方案。
- T31：空心试样候选记录在 RA 区域，核心机制命中。
  不过 RA 前后同次落盘，只能依据自述分阶段，不能验证其净增量。

全量阶段若要比较 RA 的帮助，应先保存 CCA/PMA 阶段产物并记录哈希，
再发送或执行 RA 阶段，最后统一冻结后揭答。
这是评测取证的改进，不能混作两个方法本身的规则补充。

## 适用边界与待检假说

当前三题没有验证出新的方法适用边界，以下仅是后续必须区分的边界问题：

- 生成搜索框架不能替代未掌握的物理效应、材料知识和工程参数。
  知识缺口不自动说明结构方法不适用，也不能靠树形表达消除。
- 从原系统改进转向角色重分配或替换时，
  必须区分真正需求和原系统结构事实。
  T31原容器灌满腐蚀液不宜被默认为一切替代设计必须保留的要求。
- 已知方案解读、预测下一项发明、行为谜题、科学假说与未知方案设计，
  不能按同一个盲解命中率比较。
  索引中的 T16、T42 已把方案写入题干，
  后续可作结构还原测试，却不能算独立生成证据。
- 答案缺失、关键图示缺损或原书省略关键前提时，
  应记录证据不足或部分可比，不能直接归 C 或强行报 A。
  T07现已补查图2、图3，原先的缺图限制已解除，实际共面与精度条件仍待验证。

正式全量结果再分别归纳“特别适用”“可用但搜索效率弱”和“边界候选”。
若提出 Skill 补充，应先依据多题证据核对现有规则，再区分改写、提示和知识补充。
