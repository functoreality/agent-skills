## 原书机制与约束

解答包的原文片段为：

> 冰及冻结在冰里的磨料颗粒组成的

> 抛光表面是刚性的，同时又能让大量冷却水全面通过

来源为解答包转引的
[Page 28，L997–1000](../../_private/references/altshuller/Altshuller-creativity-as-an-exact-science.pages-1-78.md#page-28)。

书中用含磨料的冰替换树脂光模，冰在抛光时融化，在工作面局部提供水。
磨料颗粒承担具体的抛光作用，冰固相承担支承与保持工作面的作用。
这里通过物质相变把支承介质变成冷却液，避免依赖预先打在承载面上的宏观孔洞。

对题干约束的判断：

- 树脂是原系统事实，题干没有明令禁止替换，因此换成含磨料冰不直接违背已声明约束。
- 冷却液未限定种类，选择水没有直接冲突，但原工艺能否接受水仍属工程前提。
- 方案在构造思路上同时保留固相工作面与界面供液，符合书中针对的矛盾。
- 书中片段没有证明冰光模的面形稳定性、磨料保持能力或供水量满足实际加工要求。
  连续融化会消耗工作面，供水量取决于融化速率。
  因此应区分“原理上提供组合机制”和“已验证满足所有光学加工指标”。

## 冻结候选逐项对应

| 候选 | 与原书的机制关系 | 对本题另行成立的情况 |
| --- | --- | --- |
| S1 周边喷液加偏心往复 | 不对应。液体经边界与相对运动进入，没有固体光模自融供液 | 可能成立，中心供液和膜寿命待验证 |
| S2 抬起灌液后加工 | 不对应。以接触时序分离供液与加工 | 可能成立，节拍和重复接触质量待验证 |
| S3 微孔树脂渗流 | 不对应。仍以现成通道输送液体 | 微孔是否损失加工能力未知，不能借书中答案证明 |
| S4 背面流道冷却 | 不对应。以导热将界面热量传到背面液体 | 不满足界面直接供液的严格题干要求 |
| S5 修整孔缘 | 不对应。只处理一种假设的孔缘损伤 | 依赖孔缘突出是主要失效原因，目前没有证据 |
| S6 冻结冷却液光模自融 | 对应核心相变供液机制，且工作体本身是固态冷却液 | 可能记忆贡献。缺少冻结磨料的具体结构，工程性能未证实 |
| S7 冰填树脂孔 | 仅共享冰融供液，工作体仍为树脂与填冰的组合 | 冰熔后重现孔口，与原书的完整冰工作体不同，不能算完整命中 |

S6 的对应不是因为都属于“改材料”或“相变”大类，
而是答案前已经写出工作体由固态冷却液构成、在接触处融化、直接产生所需冷却液三步。
缺失的冻结磨料是实现抛光作用的重要构成，不能在揭答后默默补入冻结候选。

## 揭答后的实际路径调整

本例无需为追到核心供液机制重新构造一条 B 类路径。
但若要从 S6 走到原书具体方案，仍发生了以下明确调整：

| 冻结前节点或展开 | 揭答后节点或展开 | 调整性质 |
| --- | --- | --- |
| 固态冷却液制成光模 | 采用水冻结形成冰光模 | 从通用物质选择落实到水，答案提供具体选择 |
| 固体冷却液具备抛光适配性，待验证 | 将磨料颗粒冻结在冰中 | 新增具体材料结构与抛光作用的桥接层，来自答案 |
| 接触区受热熔化产生液体 | 抛光时冰融化，在工作面产生冷却水 | 核心路径未变，答案明确冷却液来源 |
| S1 为工程试验首选，S6 条件式保留 | S6 成为与原书对应的重点，仍保留性能验证 | 揭答后的优先级调整，不能当作答案前搜索效率 |

原书方案的完整短路径可表述为：

1. 同时获得可支承磨料的工作面与接触区冷却液。
2. 使工作体的固相承担支承，局部液相承担供液。
3. 以冰作为可熔工作体，把磨料颗粒冻结在其中。
4. 抛光过程中的冰融化在接触区生成冷却水。

从供液方式转向界面生成液体值得尝试，因为它直接绕开承载面开孔这一损失路径。
从“生成液体”转向“固态工作体熔化”利用了冷却液可形成固相的性质。
但本轮这个关键转折有记忆线索在先，不能用揭答后的完整链证明两个 Skill 必然会找到它。
磨料冻结结构则是本轮明确由答案新增的知识。

## 与既有 Skill 规则的关系

事实与方法解释分别判断如下：

- CCA 的“4.3.2 选择拆分依据并产出候选子因素”与
  “4.3.4 验证拆分”已经要求保留机制差异、必要条件与直接发生机制。
  本题未提供有孔变差的实测机制，本轮只能写条件式缺点树。
  这首先是输入证据不足，不能直接诊断为 CCA 不会发现原书方案。
- PMA 的“3.3 选择展开模式并寻找直接手段”及
  expansion-patterns.md 的“科学效应或方案大类”
  已允许按科学效应和作用方式横向展开。
  从外部输送改为工作面原位生成液体，在既有规则下可以表达。
  本轮 PMA 主树没有展开“原位生成”，属于实际展开覆盖的遗漏，
  不是 Skill 明令排除了该方向。
- expansion-patterns.md 的“具有性质的对象”允许引入中介对象与分析构造过程，
  “选择、参数化与实施条件”允许补出组件与资源。
  把磨料冻结在冰中可以作为具体光模的材料结构，既有规则可安放这一层。
  但“可安放”不等于本轮已生成，也不等于模型必然知道该结构。
- PMA 的“3.4 确定组合关系、验证拆分并检查跳步”要求检查必要条件。
  若把目标扩为完整抛光系统，承载工作面、磨料作用和界面供液应共同成立。
  本轮局部根只覆盖供液，因此缺少完整抛光作用的细化并非纯粹格式问题。
