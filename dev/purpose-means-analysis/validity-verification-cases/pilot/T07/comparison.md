原 CCA 虽然声明只分析 S2 的局部机制，仍存在根选择问题：
“斜绳长于垂直距离”本身是几何事实，不必然造成不合格的测量。
长度差在 0.5 米以内，或读数经过正确反演时，都可能保留该事实而满足要求。
真正应避免的是“S2 的水深估计误差超过 0.5 米”。
原先还隐含了估计映射 ĥ=L，即把绳长直接作为水深估计值。
原书改用 ĥ=f(L1,L2,d)，因此无须消除绳索倾斜。
这是观测量到估计值的映射缺失，不只是原有分支的优先级安排失当。

基本几何知识在答案前已经可用，不是揭答后才学到的新物理定律。
但是“双浮标共用一个沉底点”的结构是原书答案提供的关键设计信息。
冻结分析没有自行选择它，不能把“知识原本已知”替换成“方案已被生成”。

从问题走向该机制的一条完整短路径如下。
这是揭答后的方法重建，不是对答案前搜索历史的描述。

* 从飞机获得水面至河床的垂直距离：选定几何反演方向
	* 构造把水下距离转为水面可见间距的几何结构
		* 用已知长度的线段约束沉底点与两个水面端点的位置
			* 将两根绳的一端系于同一石块：末端（答案提供的结构）
			* 将另两端分别系于两个木块：末端（答案提供的结构）
			* 使绳保持张紧且足够笔直：暂缓（须核验水流及绳索弯曲）
		* 由已知边长和水面端点间距求三角形高
			* 在一个水面木块上附长度基准：末端（答案提供的米尺）
			* 从飞机照片求两个水面端点的真实间距：暂缓（透视与分辨率未给）
			* 由三边关系计算三角形高：末端（下节给出计算式）
		* 使三角形高等于垂直水深：暂缓（须有竖直平面条件）

值得尝试这一转折的理由不只是“答案这样写”：
飞机容易观察水面浮物，却不容易读出水下刻度。
S2 已揭示单绳倾斜会破坏直接绳长读数，
因而应先问“能否再观测一个量，恢复几何关系”，再问如何减小倾斜。
加入第二个已知长度约束是一类合理尝试。
不过，为什么恰好选双浮标构型仍含有设计搜索，PMA 不保证会选中它。

## 几何核对与约束满足性

下列推导沿用初次报告自设的拉丁字母：两个水面点A、E对应原图А、Б，沉底点B对应原图В。
已知直线绳长为 L1、L2，水面端点间距为 d，且 d>0。
取 A=(0,0,0)、E=(d,0,0)、B=(x,y,−h)。

则由两条距离约束可得：

```text
x = (L1² − L2² + d²) / (2d)
q² = L1² − x² = y² + h²
```

q 是三角形中从 B 到 AE 直线的高。
**只有 y=0，即 A、E、B 构成竖直平面时，才有 h=q。**
如果底点偏离 AE 所在竖直平面，三边给出的只是 q，不能唯一给出 h。
因此“已知三边即可求三角形高”成立，
“三角形高天然就是垂直水深”则还需一个条件。

例如 L1²=50、L2²=65、d=5 时，x=1、q=7。
B=(1,0,−7) 与 B=(1,√24,−5) 都满足同样的绳长和水面间距，
垂直水深却分别为 7 米与 5 米。

一种可能支持该条件的理想化是：局部水流同向，浮标所受水平力与拉绳处于
同一竖直受力平面，两个浮标沿同一水流轴排列，绳可视为直线。
这种条件下不用知道流速数值，就可能利用几何关系求深度。
若存在不同方向的局部流、风力或明显绳弯曲，前提不能自动成立。
PDF图3已明确作者意图采用共竖直平面内的直绳模型，
但图示没有补出在实际流场中保证共面、张紧与直绳的机构。
原文“河水越深……距离越小”还依赖所选构型。
底点的水平投影处于两浮标之间时，
有 d=√(L1²−h²)+√(L2²−h²)，该单调关系成立。
两个浮标位于投影同一侧时则采用两项之差，不能照搬同一单调结论。
原图3现已确认采用同侧构型。若L1>L2，
有d=√(L1²−h²)−√(L2²−h²)，在0<h<L2内间距随深度增大。
例如L1=10、L2=8，h从3增至6时，d约从2.123增至2.708。
因此原书“越深、间距越小”与图3的同侧定长直绳模型局部不一致。
这不妨碍在理想模型中使用三边反演，不能据一句单调描述判整套方案无效。

## 既有规则与执行诊断

这里的问题主要是既有规则执行不充分，不是两个 Skill 完全没有相应入口。

- [CCA Skill](../../../../../skills/causal-chain-analysis/SKILL.md)
  步骤1“理解用户问题”与步骤2“推导本质初始缺点”要求辨认真正应避免的客观状况。
  原树把绳长与水深的物理不等式作为局部根，
  没有继续区分物理状态、读数映射与超限误差。
  原书保留该物理状态却改映射即可构成反向核验，故根选择诊断成立。
- [PMA Skill](../../../../../skills/purpose-means-analysis/SKILL.md)
  步骤3.3“选择展开模式并寻找直接手段”
  要求测量判别展开，并保留直接中间层。
  本轮原先从“探测体位置”直接选定读入水绳长，
  没有充分展开“从哪些可观测量求垂直水深”的反问题。
  该节还要求显式保留条件、筛选规则和变换步骤。
  因而 ĥ=L 这一可更换的读数规则本应作为独立变换接受检查，
  不能把它默认为不可改变的测量定义。这也是已有规则的执行遗漏。
- PMA [展开范式](../../../../../skills/purpose-means-analysis/references/expansion-patterns.md)
  第5节“测量、判别或评估”
  已包括细化可观测信号和列举测量原理。
  第2节“具有性质的对象”也包括选择对象结构、引入中介对象。
  第二个浮标本可作为中介结构进入搜索，不能说 Skill 没有结构变化入口。
- [CCA Skill](../../../../../skills/causal-chain-analysis/SKILL.md)
  步骤5“检查五：你能想到的所有解决方案，是否都对应末端缺点？”
  已要求从解法反查结构覆盖。
  原自查对 S2 主要考虑减阻与配重，没有想到“保留倾斜而修正读数”，
  所以这一步没有形成足够独立的观察角度。
- PMA Skill 步骤3.4“确定组合关系、验证拆分并检查跳步”
  已要求 And 局部完备性。
  它也适用于揭答后的三角形方案：必须继续核查竖直平面和直绳条件，
  不能为了对上原书而放过这些前提。

可供另题验证的改进建议，仅作为执行提示，不修改 Skill：
