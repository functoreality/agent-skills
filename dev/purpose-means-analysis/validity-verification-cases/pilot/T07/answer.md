# T07 原书答案摘要

公开版仅保留题答所需的核心摘要和短摘录，不连续转载原书论述。
试点最初归档的OCR揭答片段在本地私有输入中，
校验与版本说明见[原始输入清单](../../sources/private-inputs-manifest.json)。

用两根已知长度的钓丝，把两个水面木块分别连接到同一沉底石块。
在一个浮标上设置米尺，从飞机拍摄水面浮标，
用照片中的浮标间距与两绳长度求出三角形的高。

后续PDF核订辨清图中字母为А、Б、В、Г：
已知两绳边АВ、БВ，照片测АБ，所求水深为ВГ。
图3采用两个浮标在石块竖直投影同一侧的理想构型。
原书确有以下单调描述：

> 河水越深，木块А与Б的距离越小

它与同侧定长直绳模型的方向关系、以及共面和精度前提，
均在[对照报告](comparison.md)中分开讨论，不因原文这样写便视为已经验证。
