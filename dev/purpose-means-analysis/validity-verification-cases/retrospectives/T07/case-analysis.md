# T07 事实差异与两项归因

## 范围与证据

本轮复盘对象是第一次已冻结的T07试解，不改写其搜索历史。
原书核心答案是双浮标、两条已知长度绳、同一沉底点，
利用水面浮标间距反演深度。
参考解仍有共面、直绳、资源与精度等前提，不以其权威性替代核验。
PDF图文的单调方向疑点见[原对照报告](../../pilot/T07/comparison.md)。

主要证据：

- [答案前分析](../../pilot/T07/before-answer.md)第31–61行：已有五类测深原理。
- 同文第66–82行：S2局部CCA根、直接展开及后续干预方向。
- 同文第84–107行：S1至S5具体候选，第109–143行为RA新增S6。
- [揭答后的实际变化](../../pilot/T07/comparison.md)中“B：原展开到新展开”一节。
- [工作流核对](../../reviews/workflow-audit.md)及[冻结指纹](../../pilot/freeze.json)。

本轮区分三层证据：已记录的输出事实、对搜索遗漏的解释假说、
候选指令可能产生的行为变化。后两层不能由第一层直接证明。

## H1：中间状态、读数规则与局部结果的界限

### 已发生的选择

局部CCA以“水下绳长大于两端点的垂直距离”为根，
展开到水流使浮标偏移、使绳弯曲，随后主要提出减阻、配重等方向。
若要分析S2能否达标，相关失效事件是水深估计误差超过允许值。
这是用于候选方案的假设性失效分析，不声称现场已经测得超限。
原文也明确说这是S2的局部机制，不是全任务初始缺点，不能忽略这项声明。

设深度为h、信号为L、读数规则为h_hat=f(L)。
原选择近似固定了f(L)=L，再要求物理过程使L接近h。
如果不把f固定，就会看见两类不同干预：

- 改变物理状态，减小当前读数规则带来的误差。
- 在信息足够时改变读数规则，保留原物理状态而减少结果误差。

如果本次已明确固定为直接读数方案，原局部CCA仍可继续保留，
它解释了这一手段的误差来源，不能仅因局部根是中间状态就判整段分析错误。
应补清f(L)=L及误差阈值，并在上层PMA保留其他读数规则的探索入口。

第二类需要另作设计，不能把设计动作写成CCA里的原因。
CCA应识别规则与物理条件的作用，具体构造可切到局部PMA。

### 为什么现有规则还值得检查

[CCA Skill](../../../../../skills/causal-chain-analysis/SKILL.md)
步骤2已要求沿客观后果追到本质初始缺点，
并以静电、电流和疼痛的区别说明不应止于中间因素。
所以不是完全缺少原则，也没有证据说该Skill禁止检查读数规则。

可改进的假说是：对中间量、代理指标与解释规则，
现有原则没有给出本次执行实际用上的具体判断问句。
增加一个在选根时触发的操作，可能比收尾时再说“检查目标”更容易落实。

**竞争解释**仍包括：一次性的执行遗漏、S2分支投入不足，
或即使有该问句也仍会选定修补物理过程。
当前记录不能区分这些原因的贡献，不把“未执行”直接定为“指令表述导致”。

### 最小修复及其不足

若本轮目标是解释达标失败，最小修复是以误差超限为局部结果，并显式列出f。
若只保留直接读数法的局部分析，则标明f(L)=L这一前提，
不必删除原树，但在上层保留无需该规则的新路径。
这能避免把某一手段的局部要求升为所有方案都必须满足的要求。
但若只有一个受未知水平偏移影响的L，换公式不能凭空增加信息。
修复H1并不自动生成双浮标，也不证明单绳已有足够数据。

## H2：局部测量方案过早固定了可读量与结构

### 已发生的选择

原分析已有摄影反演、下沉计时、声时测距与水波传播等方向。
因此不能诊断为“不会间接测量”或“只想到一种观测量”。
更窄的事实是：S2及其所在探测体位置分支先固定单绳长度读数，
遇到读数与流动问题后，没有再把辅助结构与可读信号一起重新设计。

原书答案让水下量通过辅助结构约束水面间距，
改变了从飞机上需要读的东西。
这比“找到更好的绳长读取设备”多了一步对测量系统本身的设计。

### 已有入口与缺失操作假说

[PMA Skill](../../../../../skills/purpose-means-analysis/SKILL.md)步骤3.3
已包括测量判别、隐藏条件与变换规则。
[展开范式](../../../../../skills/purpose-means-analysis/references/expansion-patterns.md)
第2节允许中介对象，第3节允许输入输出变换，第5节允许测量原理和信号。
这些类型足以表达原书方案，没有依据新增一个永久的“双参照对象”节点类型。

假说是：这些入口仍主要停在可选方向，
缺少“现有读数受阻或信息不足时，联合考虑可读信号与辅助结构”的操作提示。
原Agent实际读过这些文件，仅再加一条阅读提醒不一定有效。
候选应提供新的可执行检查，而非只增加交叉引用。

竞争解释包括：现有提示已足够，本次只是没有选择该分支；
原书构型依赖额外设计联想；或约束与信息不足使执行者合理地暂缓了这条路径。
因此当前只能提出策略候选，不能断定缺少它就是漏解原因。

### 最小修复及其不足

先区分待求目标、可读量、已知关系及未控制影响，
检查能否区分任务要求区别的情形。
若不足，再探索参照对象、可控条件或辅助过程，让目标转成可读量。

在T07中，这会为“构造水下距离到水面间距的关系”留下明确入口，
可能继续到双浮标，但通用提示不应直接写出这一答案。
该入口还可能产生其他有条件方案，不能只以是否复刻同一构型判断价值。

## 两项发现的关系

| 指导条件 | 可以改变什么 | 仍不保证什么 |
|---|---|---|
| 只考虑H1 | 不把中间几何状态直接当最终失败，可检查估计规则 | 观测足够、能设计新结构 |
| 只考虑H2 | 在正向测量功能下探索新的信号与辅助结构 | 在错误的局部根下仍可能耗费精力去消除倾斜 |
| 同时考虑 | 目标事件与测量系统设计更容易衔接 | 必然生成双浮标、所有工程前提成立 |

这是一张作用机制推演表，不是四组Agent实验结果。
两项可分别修改，不等于两项原因已被实验分离。
具体候选、适用边界与验证需求见[候选规则](candidate-rules.md)。
