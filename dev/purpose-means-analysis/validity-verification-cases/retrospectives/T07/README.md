# T07：从 B 类案例提炼通用指令的示范

本轮完成两项发现的事实核对、归因假说、候选补丁及跨领域正反例推演。
按用户明确选择，**不做前瞻盲试，不修改两个 Skill，不启动全量分析**。
T07第一次试解仍为B，答案前文件与题干的冻结记录保持不变。

## 两项发现与建议

| 项目 | 可查事实 | 通用改进候选 | 当前建议 |
|---|---|---|---|
| H1：初始缺点识别 | S2局部CCA把绳长大于垂直距离作为根，未明确读数规则与误差阈值。 | 初始缺点拟用中间状态或代理指标表述时，追到既定不良结果，并显式检查使用或解释规则。 | 优先考虑对CCA原有步骤作短补充，暂不合入。 |
| H2：测量方案展开 | S2固定为读取单绳长度，未生成双浮标与水面间距反演。原分析其他分支已有间接测量。 | 观测受阻或信息不足时，检查能否设计辅助结构、参照或可控条件，让目标转成可读信号。 | 放在现有测量范式下作为有条件策略，不新增永久节点类型，先保留提案。 |

**H1核对搜索目标与局部前提，H2扩展可探索的测量结构。**
H1单独不能从不足的信息中恢复水深，H2也不保证选中原书构型。
两者是两个可分别改动的指导点，不是已经证明互相独立的失败原因。
相较初步报告，H1进一步保留了固定方案局部分析的正当性，
不把所有中间状态根都判错，也不强制将每棵局部树改成全局目标。

## 本轮能够与不能够判断的内容

- 能确认两项具体分析变化，并将它们与既有规则、通用操作相联系。
- 能用跨域例子与明确反例检验表述是否有内容、是否需要加边界。
- 独立计算核对了单绳信息不足、算法耗时反演、重复观测失效等示例。
- **没有测过加入候选指令后，新的解题Agent是否更容易生成原书答案。**
- 推演支持候选规则有合理的作用机制，不证明指令缺失是本次漏解的唯一原因。
- “修正后可表达答案”“能生成该答案”“能完成现场工程实现”仍分开判断。
