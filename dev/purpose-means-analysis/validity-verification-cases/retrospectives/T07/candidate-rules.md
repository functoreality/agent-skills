# 两项候选规则与最小改动提案

本文件只展示提案，不编辑正式Skill或其learnings文件。
两项目标是操作化已有入口，不把当前案例的物件名称写成通用要求。
来源及竞争解释见[案例归因](case-analysis.md)。

## H1：在选根时检查中间状态与真实不良结果

### 从具体经验到一般操作

| 层次 | 表述 | 判断 |
|---|---|---|
| 案例动作 | 不必消除绳倾斜，可以改变水深估计方式。 | 太依赖本题，留作例子。 |
| 共同机制 | 中间状态只有经过某种使用或解释过程，才产生所关心的损失。 | 可跨领域，但还缺执行动作。 |
| 可执行提示 | 拟把中间状态或代理指标作根时，明确它到已确认不良结果的客观关系，检查其中可改变的规则。 | 作为候选。 |
| 过度抽象 | 先找到真正问题，多换角度思考。 | 与既有原则相近，难以触发新的具体操作。 |

### 触发、动作、边界

- **触发**：准备选定初始缺点或一个局部缺点，表述指向中间状态、代理指标、
  参数偏离，且尚未说明其怎样构成已确认的不良结果。
- **动作**：沿客观关系追到不良结果，写清造成损失的使用、读数或判别过程。
  区分固定验收要求与可改变的实现规则，并核对是在分析全任务失败，
  还是已选方案的局部条件。
- **预期变化**：保留“改变物理状态”与“改变规则或实现方式”等不同干预入口。
  规则执行可作为客观机制分析，设计新规则则另转局部PMA。
- **局部分析**：已明确固定的方案条件可以保留为局部根，写明依赖前提。
  放宽该手段时回到上层PMA，不强迫把每棵局部树都改成全局目标。
- **排除**：用户明确把该状态本身列为验收要求，或该状态就是直接不良结果，
  不得因另一个指标合格而把它取消。
- **停止**：关系与目标已经清楚后继续正常展开，不对每个后续节点机械重做。
- **不确定时**：保留现有根确认流程，不擅自改用户目标或已确认的初始缺点。

### 建议位置与最小补丁

位置：[CCA Skill](../../../../../skills/causal-chain-analysis/SKILL.md)
步骤2的第4项之后，沿用已有根确认流程。
本例没有证据要求推翻“追到本质初始缺点”的原原则。

```diff
 4. 依据因素定义，调整优化初始缺点的表述
+   若候选表述是中间状态或代理指标，先问：它通过什么客观过程，
+   在什么使用或解释规则下造成已确认的不良结果？将其中可改变的
+   规则显式化，不把该状态默认当作必须消除的最终结果。
+   若只分析已选方案的局部条件，写明其依赖前提，不把局部要求升为全局要求。
+   用户已将该状态本身列为要求时仍须保留，不确定时按现有流程确认。
```

建议级别：**需审**。
输出中的选根与展开有直接证据，但是否构成错误还需结合局部分析范围。
补充与原规则兼容，实际减少误用的收益尚未测。
若暂不固化，可将以下内容作为learnings候选，待用户决定去向：

> T07局部CCA把绳长与深度的物理差异作根，遗漏了读数映射和超限误差。
> 原步骤2已有本质缺点原则，可试在选根时加入中间状态到既定不良结果的具体问句。
> 尚未验证表述缺失的因果贡献，不能据此宣称该提示必然改善解题。

## H2：在观测受阻时联合设计信号与辅助结构

### 从具体经验到一般操作

| 层次 | 表述 | 判断 |
|---|---|---|
| 案例动作 | 加第二浮标和绳，用水面间距反演水深。 | 属于答案，不写进通用指令。 |
| 接近案例的启发 | 单个物体不够时，多加一个同类物体。 | 仍可能过拟合，也未保证信息增量。 |
| 共同机制 | 让目标差异经可设计的关系变成可观测差异。 | 可跨域，须给触发和检查方法。 |
| 可执行提示 | 信号难读或不足时，明确目标、信号、关系及未知影响，检查能否通过辅助对象或可控条件使所需状态可区分。 | 作为候选。 |
| 过度抽象 | 搜索更多观测量，考虑所有可能结构。 | 无停止条件，容易增加无用分支。 |

### 触发、动作、边界

- **触发**：当前父目的需要得到测量或判断，已选信号难以获取，
  或不能在所需精度下区分任务必须区别的状态。
- **动作一**：明确待求目标、能读取的信号、二者已知关系及未控制影响。
  不要求已有完整公式，关系未知则显式留下待查或待设计项。
- **动作二**：检查不同目标状态是否仍可能产生相同或不可分辨的信号。
  信息不足时，探索参照对象、可控输入、重复观测或辅助结构，
  使目标差异转成可读信号。这些是开放示例，不是封闭策略清单。
- **动作三**：说明新观测实际补了什么区别能力，核对模型前提与允许误差。
  多一个数值或重复一条相关信号，不自动等于增加足够信息。
- **约束**：保留资源、成本、精度与不干扰条件。
  条件暂不可满足的方向按已有规则标暂缓，不据此声称方案已实现。
- **排除**：已有信号已经足够完成当前目的时，不强制增加测量。
  只需某个总量时，不要求恢复所有内部未知量。
- **停止**：形成足以继续构造的区别关系，或明确指出仍缺什么信息、知识或条件。
  不要求每个测量节点都填写同一套长表。

### 建议位置与最小补丁

主要位置：[PMA展开范式](../../../../../skills/purpose-means-analysis/references/expansion-patterns.md)
第5节“测量、判别或评估”。现有对象、变换和测量类型已经可以表达该方向，
本提案不新增永久节点类型。

```diff
 - 列出测量原理、数据来源和判别过程
+
+若现有信号难以读取，或不足以区分任务要求的状态，先明确待求目标、
+可读信号、二者关系及未知影响。必要时探索参照对象、可控条件或辅助结构，
+使目标变化转成可读信号，并说明新增信息补足了什么区别能力。
+保留模型、资源、精度和干扰条件，不能满足的分支按现有规则暂缓。
+已有信号足够时不强制追加观测，也不要求恢复与任务无关的全部状态。
```

为避免调用时机不明，可同时在[PMA主文](../../../../../skills/purpose-means-analysis/SKILL.md)
步骤3.3现有第4条后加一条短路由，不把全文重复进主文：

```diff
 4. 若手段是输入输出变换、测量或评判，可拆输入、输出、所用原理、
    评判准则或实现机制
+   当现有信号难读或不足以判断时，按展开范式第5节检查信号关系，
+   必要时转入辅助测量结构的设计。
```

这是一个策略及其路由的同一提案，不把两处编辑算作两项独立改进。
它们仍沿用现有逐层展开与And/Or关系，不把检查清单直接塞作主树的兄弟节点。

建议级别：**存疑，优先作为可选策略试用**。
该方向解释了漏掉的搜索区域，但未证明缺少此提示造成漏解，
也未证明该提示足以生成原书构型。
若暂不固化，可将以下内容作为learnings候选，待用户决定：

> T07全局已有多种间接测量，S2局部仍固定为读取单绳长度。
> 可试在观测受阻时联合设计可读信号与辅助结构，并检验信息增量。
> 需保留条件与停止标准，防止增加无关测量；实际生成收益尚未盲试。

## 取舍与本轮建议

- 优先审议H1的短问句，检查它是否把已有原则变得可执行，
  而不是重复一遍“找真正问题”。
- H2更适合作为测量范式中的条件策略，先不改全局拆分顺序，
  也不把“增加对象”“增加观测”升级为每个节点的义务。
- 两个目标Skill目录均未发现learnings.md，不能把不存在的历史记录算作先例。
  本轮只提供可存档的观察文本，没有创建或编辑目标Skill的learnings文件。
- “已有原则但未落实”是诊断起点。是否需要改写指令、提高触发优先级，
  仍要通过边界推演及后续试用来判断。
- 两项提示本轮均未合入。它们的跨域推演与反例修正见[迁移检查](transfer-checks.md)。
