# T13：参考机制与判定要点

以铁磁颗粒作过滤器，在磁极间形成多孔结构，接通磁场时缩小孔隙以捕尘，关闭时增大孔隙以清理。将工具碎化并由磁场控制。

书中回提两磁铁间放铁磁粉末的过滤器，并把多层金属网过滤器分割、联合、多孔、受电磁场动态改变尺寸解释为技法组合。

## 预先登记的核心判定

- 过滤介质为可重排的铁磁颗粒
- 磁场控制成形或孔隙，过滤与清理状态切换
