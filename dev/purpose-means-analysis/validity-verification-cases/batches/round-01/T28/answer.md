# T28：参考机制与判定要点

以液体样规替代固体样规，把空锥体放入水槽，逐次注水到指定高度，用同一底片从上方重复拍摄水面，得到同心圆组，与标准照片对照。

## 预先登记的核心判定

- 液面与内壁交线编码不同高度的截面
- 多水位成像并与标准轮廓对照，不要求必须同一胶片
