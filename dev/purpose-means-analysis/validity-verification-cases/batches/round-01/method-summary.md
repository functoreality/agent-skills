## 当前能力和边界

| 场景 | 本轮证据 | 能支持的判断及限制 |
|---|---|---|
| 已有系统的缺陷转为可干预处 | T34流入与流出、T13滤层状态 | CCA能组织发生机制，PMA可把干预方向落成新功能。T13有熟悉度混杂，不能量化方法贡献。 |
| 需要改变工作对象或输送形态 | T61分子输送后转化 | 现有中介对象、输入输出变换范式已有生成能力，未显示必须增加永久节点类型。 |
| 测量信号和辅助结构需要共同选择 | T28漏液面交线，T49生成电光/磁光 | 可用，但开放信号搜索不保证命中。后者也表明现有规则能生成具体转换结构。 |
| 事后恢复历史状态或时间 | T05磁变已覆盖而定时未闭合 | 需有效动态模型、初始条件和可辨识性，分析树不能替代这些知识及证据。 |
| 后期作用受限，需要先布置条件 | T46漏预置介质内部产压 | CCA/PMA/RA的表示能力可容纳，生成和连接相关分支仍可能失败。 |
| 追求原书每个具体效应或材料 | T49 Pockels与Kerr，T61材料实例 | 功能机制、具体科学效应、选材实例须分层核对。不能靠强制穷举来保证全部复现。 |

没有发现新的、已确认不在两种方法加RA适用范围内的任务类别。
这也不证明方法完整：3题漏核心，T49漏一个具体效应，
均是在揭答以后才构造解释或细化，生成能力与解释能力仍有明显差别。
对历史答案真实性、工程指标与开放搜索的非穷尽性保持边界，不以树可表达代替验证。

## 有哪些可讨论的修改

目前没有推荐立即落盘的Skill修改。
更值得继续检验的是H2与R01-O4，但不把它们自动合为一条泛泛的“多换角度”。
H2关心怎样构造可观测信号，O4关心受限阶段的条件能否提前形成，
它们的触发、误用与知识要求不同。

若未来证据足够，先核对现有PMA第3.3节与展开范式第2、3、5、6节，
以及CCA的机制、必要条件与收尾检查。
可选择改写触发条件、调整优先级、弱化误导性限制或删除冗余要求，
不默认追加一条长期强制规则。具体补丁仍需用户确认。
