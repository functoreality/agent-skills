# T05：参考机制与判定要点

测射击冲击造成的枪管磁化程度变化。钢枪管在地磁场中磁化，射击使其消磁，重新磁化需时，用测磁仪跟踪该物理量判断射击时间。刚射击时可测温，但温度很快恢复，不适合作两昼夜指标。

## 预先登记的核心判定

- 枪管射击冲击改变磁化程度
- 利用射后磁化恢复或变化与时间的关系检测，而非泛称金属探测
