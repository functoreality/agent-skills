# T61：参考机制与判定要点

以可溶于油的金属有机化合物形成真溶液，并使其在摩擦热下分解、在摩擦表面释放金属。按照含金属、溶于油、摩擦温度分解三个条件查手册选择。书中具体例为醋酸镉，称其250°C分解、溶于油，并在摩擦表面镀镉。

## 预先登记的核心判定

- 用油溶性含金属化合物避免颗粒输送
- 工作接触处受热等分解释放/沉积金属，原书摩擦热
- 具体醋酸镉及250°C仅历史实例，不作独立事实背书

具体替代方案单列，不把方法大类视作机制命中。
