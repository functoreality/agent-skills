## 参考机制与冻结候选逐项对照

参考答案有两个连续环节：装配前在深孔内预置水，
取出前加热水产生内部蒸汽压力，由球后压力把球顶出。
水是驱动介质，球不是待熔化材料。加热首先用于产生驱动力，
不只是利用球壳热膨胀差降低保持力。

| 对照对象 | 冻结稿的具体机制 | 与参考的差别 | 核心覆盖 |
| --- | --- | --- | --- |
| S1 | 局部加热壳体扩大孔径，再夹取或推出 | 没有预置液体，也未以汽化压力驱动 | 未覆盖 |
| S2 | 冷却球体使直径减小，再取出 | 不产生内部压力 | 未覆盖 |
| S3 | 振动配合外向力产生周期滑移 | 没有球后介质及汽化转换 | 未覆盖 |
| S4 | 在球面胶接或焊接拉杆，再用夹具拉出 | 从前侧固体接头传力 | 未覆盖 |
| S5 | 从既有背面通道用推杆推出 | 推出方向接近，但依赖原有通道和外部固体传力 | 未覆盖 |
| S6 | 用低熔点球，取出时熔化并收集球材料 | 相变对象是球，产物是液体，目的为消除固体形状 | 未覆盖 |
| S7 | 选择性溶解牺牲球，排出溶液 | 消耗球体，没有保留球并由内部压力推出 | 未覆盖 |
| S8 | 脉冲加速壳体，用球的惯性产生相对外移 | 无球后汽化介质，转换为惯性驱动 | 未覆盖 |
| 阶段一暂缓液压方向 | 要求球后密闭受压腔与原有供压通道 | 未给出预先放水、内部汽化、不需持续供压口的办法 | 未覆盖 |

预置可汽化介质、取出时内部产压两个子环节都未覆盖。
因此没有 A-CP 或 A-RA 子项，不能用“加热”“相变”“顶出”等词的重合算命中。
阶段二的真实新增仍是 S8，参考机制并非 S8 的细化。

## B 类：从原展开到新路径

以下变化均发生在揭答后，不补写进冻结稿。

### 原节点与实际调整

| 原节点或展开 | 揭答后的新节点或展开 | 调整类型 |

| 暂缓液压要求“原有供压通道” | 分开“外部连续供压”和“腔内介质受激活产压” | 边界修正，原有通道只约束前一类 |
| 球后受压腔未提供，作为暂缓理由 | 若深孔有余隙，在装配前保留可容纳介质的球后空间 | 将一部分未知前提转为条件设计问题 |
| 工作阶段与取出阶段分离只支持施加外部操作及牺牲球 | 装球前预置少量介质，取出时才激活 | 时间使用方式变化 |
| 热量只接到尺寸变化或球熔化 | 热量接到液体汽化、压力建立、球面受力 | 知识调用与中间转换桥接变化 |

这条路径并非把“现成压力腔”从未知改记为已知。
题干没有给出深孔余隙、密封性或球的压入深度。
其中孔深是未知既有条件，若原孔足够深，压入位置和放水量可以成为设计变量。
若现有孔不允许保留球后空间，此方案仍受阻，是否允许改孔须另行确认。

		- 在泄漏与空间扩张期间维持有效压力：维持条件
	- 将压差转化为足够的外向行程：And
		- 使压差作用于球后的有效投影面积：压力传力机制
		- 在脱离前提供足够推力及膨胀行程：运动条件
		- 在孔外收集退出的小球：捕获操作

近似起动判据为 `Δp·A_eff > F_hold`。
Δp 是球后与孔外压差，A_eff 是有效受压投影面积，F_hold 是保持力。
该判据不保证完整排出，还需介质量、供热、密封及行程条件共同成立。
受限空间内的沸腾温度随压力变化，不能把常压水沸点直接当作操作温度。

### 为什么从题干出发值得尝试

题干有压紧小球、金属壳及装配后延迟取出的时序。
紧配本来产生保持力，也提示有条件形成限制泄漏的界面。
金属壳可传热，时间分离允许把事后难以送入的介质在装配前送入。
这为“先放入、后激活”的驱动介质提供了探索理由。
这些联系使其值得生成条件候选，但并不推出孔后必有空间或密封一定足够。

## 事实、归因假说与可进一步观察的操作

### 已观察事实

- 阶段一已经接受 S6、S7 的装配前材料选择，未把所有预置操作排除在任务外。
- 阶段一也提及液压方向，但要求原有供压通道并暂缓，没有展开局部产压。
- 阶段二明确区分新增资源，却仍只把球后通道当作缺失既有条件。
  预置少量新增介质没有进入候选，资源补扫没有覆盖参考机制。
- 参考答案补充“深孔”及放水操作。该条件不能倒填为题干明示资源。

### 归因假说

- 主要问题可能是展开执行与边界过早收窄：把压力驱动绑定到事后供压通道。
- 原 CCA 聚焦保持力，PMA 的驱动力支路又偏向工具连接，内部产压优先级不足。
- 预置和局部产压需要将空间、时间与介质转换连接起来，六维列表本身没有保证该连接。
- 水汽化、压力传力属于通用知识。记录不足以证明知识完全缺失，
  更像没有及时调用和桥接，但该归因仍是单题假说。
- 没有证据表明主要原因是预算不足，也不能由此判定 CCA 或 PMA 对此类题无效。

### 对照现有 Skill

- CCA“4.3.1 目标与基本原则”和“4.3.4 验证拆分”要求保留机制差异及必要条件。
  本题阻力树不能自然穷尽全部驱动力来源，需要单独衔接实现分析。
- PMA“3.3 选择展开模式并寻找直接手段”与“3.4 确定组合关系、验证拆分并检查跳步”
  已要求先展开有区分度的方案大类并补足中间转换，本稿没有充分执行压力驱动分支。
- 展开策略“2. 具有性质的对象”已有引入中介对象，
  “6. 选择、参数化与实施条件”已有为实现方案构造必要条件。
  因此不能把“允许引入水”和“条件可以设计”直接说成 Skill 缺少规则。
- 展开策略“3. 输入输出变换或功能系统”已能容纳热输入到压力再到位移的实现层级。
  缺的是本次没有生成并走通该路径，尚无证据要求新增科学效应目录。

可进一步观察的通用操作是：当任务存在装配与使用的时间分离，且事后作用通道受限，
检查某项缺失条件是否能在装配前预置，再由现有可穿透边界的作用激活。
触发条件应包括允许预置以及工作阶段稳定，不能仅因“稍后要取出”就默认允许加介质。
排除条件包括禁止新增物质、预置干扰原功能，或所需封闭空间无法形成。
跨域正例：远程设备部署前保存可启动恢复镜像，故障时从本地镜像引导恢复，
把故障后可能中断的下载通道换成提前存储与后续激活。
误用反例：无孔底的贯通孔里滴水，仍宣称可在球后积聚蒸汽压力，遗漏了压力边界。
这些只是供后续跨案例检验的观察方向，本次不设计或实施 Skill 补丁。
