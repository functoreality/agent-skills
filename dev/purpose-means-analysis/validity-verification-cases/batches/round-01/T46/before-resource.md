## 任务与约束

题干事实：仪器金属壳的孔内压紧一个小球，隔一段时间要取出，取出困难。
硬约束：不能改成可拆卸结构。

采用的工作边界：保留壳体及孔的使用功能，不把永久破坏壳体作为解法。
小球是否必须完整保留、是否允许预先改变球材料，题干未说明，分别提出条件候选。
孔是否贯通、球是否露出、球的工作载荷、允许温度和接触介质均未知。
这些信息影响候选筛选，现阶段不据此冒充已验证方案。

## 方法路由

这是保留原系统的局部缺点，先用 CCA 追取出阻力的机制。
从法向压力、界面剪切、取出力传递三处形成干预方向。
构造临时施力接口，或使球在取出时变成可排出物，需要局部新功能，另接 PMA。
两棵树不混写。优先级为过盈接触机制、取出路径、条件允许时的牺牲球体方案。

## CCA 树

初始缺点取为“小球的起拔阻力大”，与题干“太紧而困难”同一范围。
“+”表示轴向阻力贡献相加，各项不必都达到异常量级。
题干只支持压紧，以下把过盈配合视为工作假设。
黏着和孔口扣持仅是待排除的独立机制，不当成既有事实。

- 小球的起拔阻力大：+
	- 球孔界面的静摩擦阻力大：×（库仑摩擦近似）
		- 接触界面的静摩擦系数大：末端（材料配对与界面状态待核验）
		- 接触区域的总法向载荷大：×（等效接触近似 N = k_eq δ）
			- 接触的等效径向刚度大：末端（材料与接触几何参数待核验）
			- 球孔接触处的径向弹性压缩量大
				- 球的自由直径超过孔的自由直径的量大：差值
					- 球的自由直径偏大：末端（现有尺寸参数）
					- 孔的自由直径偏小：末端（现有尺寸参数）
	- 球孔界面的黏着剪切阻力大：待核验
		- 接触面间的黏着连接承载能力大：暂缓（题干无腐蚀、胶接或冷焊信息）
	- 孔口对球体的机械扣持阻力大：待核验
		- 取出路径上的最小开口小于球体所需通行截面：暂缓（孔形未知）

适用限制：摩擦式只作工程近似。球面法向力可能带有轴向分量，
孔口若有压铆或收口，应转到机械扣持支路，不能用摩擦式包办。
等效径向刚度 k_eq 可能随压缩量 δ 变化，N = k_eq δ 不是完整接触本构。
该近似用来保留压缩量和接触刚度两个干预入口，不据此计算实际起拔力。

## 局部 PMA 树

根是局部新功能“形成把球或球体材料运出原孔的取出过程”，
不把整台仪器重新设计。以下 Or 是方案空间，不声称穷尽。

- 形成把球或球体材料运出原孔的取出过程：or
	- 以暂态尺寸差形成球体通行条件：已选方案细化，And
		- 使孔相对球体产生足够的径向放松量：or
			- 对孔周壳体局部升温：末端（S1，温度范围待核验）
			- 对球体局部降温：末端（S2，温差维持条件待核验）
		- 在尺寸差消失前向孔外移动球体：末端（配合已有夹具或推杆）
	- 经临时施力接口传递足够的取出力：已选方案细化，And
		- 建立球体与外部工具的传力通道：or
			- 在外露球面连接临时拉杆：末端（S4，胶接或焊接）
			- 从既有背面通道接触球体：末端（S5，贯通孔条件）
		- 由夹具向球体施加轴向外力：末端（避开壳体局部过载）
	- 将球转化为可排出物：or
		- 熔化可熔球体后排出液体：末端（S6，材料替换条件）
		- 选择性溶解球体后排出溶液：末端（S7，材料替换条件）

临时施力接口不等于改成可拆卸壳体，但球面附加操作是否允许仍须确认。
PMA 中的热尺寸差分支是 CCA 过盈量干预点的实现展开。
可排出物分支进一步放宽“取出必须得到完整固体球”的假设，条件单独列明。

## 具体候选与从分析到方案的转换

### S1：局部加热孔周金属壳，趁间隙增大时取球

- 转换：自由孔径偏小 → 临时扩大孔径 → 局部热膨胀。
- 操作：只加热球周壳体，利用热扩散时间差，在球尚未同温前夹取或推出。
  一般需满足孔径增量减去球径增量足以抵消原过盈量。
- 前提：热膨胀为已知物理知识。壳体在具体约束下的孔径变化、
  球材料、热扩散速度和仪器耐温待核验。不能笼统认为整件同温加热就会松开。
- 约束：壳体不可永久变形，热敏部件需在可接受温度内。

### S2：局部冷却小球，收缩后迅速取出

- 转换：自由球径偏大 → 临时缩小球径 → 冷却球体。
- 操作：从外露部分定向冷却球，随后立即夹取或从已有背面推离。
  必要时与 S1 配合，形成壳热球冷的短时温差。
- 前提：多数普通材料冷却收缩是已知，球材及其实际收缩量未知。
  若壳体同步收缩，收益可能消失。
- 约束：低温脆化、结露、球面的可接近性以及球材热膨胀异常需核验。

### S3：界面微振动辅助起拔

- 转换：静摩擦阻力大 → 破坏持续静止接触状态 → 振动叠加外向偏置力。
- 操作：用超声或小幅轴向振动工具耦合外露球面，施加稳定外拉力，
  在周期性滑移时逐步退出。可先加可兼容的微量润滑剂。
- 前提：振动辅助压配拆卸属于通用工程联想，具体幅频与效果待核验。
  只有可侵入界面的润滑剂才可能起效，润滑不是必然可达的条件。
- 约束：对精密仪器的振动损伤、球面操作空间和总起拔力仍有限制。
  若是孔口几何锁住，单靠降低静摩擦不足。

### S4：在球面连接临时拉杆后用桥式夹具拉出

- 转换：直接夹持球面困难 → 建立临时传力通道 → 可承载拉接头。
- 操作：在球的外露面胶接一个拉杆，胶接承载不足时才考虑点焊拉杆。
  用支承在坚实壳体部位的桥式夹具施加缓慢轴向拉力。
- 前提：球面外露、接头强度超过起拔力均未知。
  焊接需金属球，胶接需表面状态及胶种相容。
- 约束：球必须保留原表面时，焊接不合适。
  此方案增加可施加力，不会自行降低过盈，需防止拉坏孔口。

### S5：通过既有背面通道用推杆推出

- 转换：前侧难以抓持球 → 从背面建立压缩传力通道 → 推出。
- 操作：若原孔贯通且背面可达，用细推杆或有导向的压具直接顶住球背面，
  壳体在孔周可靠支承后压出，可配合 S1、S2 或 S3。
- 前提：贯通且背面可达是未给出的条件，不能把此方案写成无条件解。
- 约束：不为本方案新开背孔，不改可拆卸结构。盲孔时本方案暂不成立。

### S6：允许替换球材料时，采用低熔点球并在取出阶段熔化

- 转换：固体球径形成过盈 → 消除球体固定形状 → 液态排出。
- 操作：预先用满足工作阶段强度的低熔点合金制球并压入。
  到取出时间局部加热熔化，用吸取、倾倒或吸液材料收集，清洁原孔。
- 前提：材料可替换、球无需完整回收，均待确认。
  可熔合金的存在为已知，工作温度、强度、蠕变与具体熔点窗口待核验。
- 约束：熔化温度应低于仪器损伤温度，且液体不能侵蚀或污染壳体。
  普通现有钢球若不可替换，不能直接套用此候选。

### S7：允许替换球材料时，使用可选择性溶解的牺牲球

- 转换：球体连续固相承载 → 逐步移除球材料 → 从孔口排出溶液。
- 操作：选择能满足压紧期间载荷的可溶材料制球。
  到期从外露球面加入不会侵蚀壳体的溶剂，逐步溶去球体并抽走溶液。
- 前提：存在同时满足工作强度、服役稳定性和选择性溶解的材料组合为待核验。
  不预设水溶盐球或聚合物球一定能够替代原球。
- 约束：球不可保留，溶剂与残留物须兼容仪器。
  溶剂从外露面即可开始作用，不必假设能先穿过紧配界面。

## 暂缓方向与停止理由

- 腐蚀黏结、孔口压铆支路：题干无证据，先保留诊断位置，不编造具体原因。
- 改变球的弹性刚度、采用可塌缩球：可能减小保持力，但球的工作功能未知，
  本轮先不引入内部复杂构造。
- 强磁直接拔球：依赖铁磁球、磁路和可用磁力，不能仅凭金属壳推定，暂缓。
- 液压顶出：依赖球后密闭受压腔和原有供压通道，题干未提供，暂缓。
- 当前已有可辨认的温度差、振动、传力接口与牺牲材料候选。
  继续精化必须补球材、孔形、尺寸、工作载荷和仪器容许条件。
  本阶段停在条件候选，不宣称获得完整工程验证。
