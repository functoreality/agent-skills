# T49：参考机制与判定要点

把电场或磁场输入变为光场输出，分别采用克尔效应或法拉第效应。

## 预先登记的核心判定

- 电场引起介质光学性质变化以测电压（原书克尔效应）
- 磁场改变光偏振以测电流（法拉第效应）
