## 六类资源及其功能

| 资源类 | 资源与来源 | 可服务的子目的及增量 |
| --- | --- | --- |
| 物质 | 题干直接给出导线与巨大绝缘支架。导线既有支承结构是否可供改装，属待确认前提 | 既有绝缘结构可以同时承担测量耦合元件功能，见 S7。沿用 S4、S6 的线侧安装不能默认导线承载能力无限 |
| 能量 | 导线电压、电流为直接给出。交流磁通及可抽取的微量电能是有条件的常识推断 | 以磁耦合为线侧电路供电，见 S8。光场为 S2、S5 新增的传感资源，不能算题干原有 |
| 信息 | 被测电压、电流为直接给出。位置、相间几何及频率可在安装时获知，是需实际获取的信息 | 固定几何可支持 S1、S2、S6 的标定。相线参数未给出，不能假定单点场信号足以反演多线状态。此项无独立新增机制 |
| 空间 | 导线与地面之间的绝缘空间是常识可推资源，具体净距未知 | 已由 S2、S4、S5、S6 用于光或无线传输。可复用既有支架所在空间部署 S7，不能侵占必要净距 |
| 时间 | 连续或周期采样机会为常识推断，交流周期仅在交流条件下存在。机械调制为新增操作 | 对静电场主动周期调制，把恒定电压转换成交流读出，见 S9。同步采样可辅助 S1、S6 滤波，但不独立解决几何误差 |
| 环境性质 | 空气绝缘、外界电场和磁场是常识可推。天气、地电位参考、背景磁场的具体状态未知 | 空气支持非接触传感，但污染及雨雪会改变电容和爬电。地电位可作 S1、S7、S9 的参考，具体接地条件待确认。除上述组合外无独立新增候选 |

表内“新增”指试解中需要引入的组件、能量或操作，不意味着题干已经提供。
题干本身没有保证足够的取能功率、可利用的绝缘子分压点或可用的视线。

## 新增候选

### S7：复用既有绝缘支架的电容通道测电压

- 资源到子目的：已有绝缘结构跨越线路电位与地电位，
  其对地电容与绝缘间距可被复用为电压信号耦合通路，
  避免为测量再造一套大支架。
- 具体机制：在允许改装的既有支架低压端设置有屏蔽的拾取电极和取样电容，
  测出导线经支架分布电容耦合到该端的交流电流或分压信号，
  地面放大并依据实测电容比例标定导线电压。
- 与 S1 的区别：S1 给出独立电极及电容分压的原理。
  S7 新增“以既有支承绝缘件作为耦合结构”的具体对象选择，
  不把它算成一种新的传感效应。
- 来源归因：资源视角触发，电容分压知识用于落实。
  不是对具体参考答案的回忆。
- 前提与限制：已有支架确实存在并允许改装，且电容耦合足够稳定。
  分布电容、表面泄漏和天气造成的误差待核验，适用于交流方向。
  若题意要求连既有绝缘支承也取消，S7 不满足该更强要求。

### S8：用线路磁场为 S4 或 S6 供电

- 资源到子目的：交流电流已有磁场，可供应线侧采样和无线发射所需的小功率，
  减少电池更换造成的维护复杂性。
- 具体机制：在导线上套一个小型开合磁芯取能线圈，
  将次级感应电压整流、稳压并给储能电容充电，
  再驱动 S4 的积分采样或 S6 的霍尔采样与间歇无线发射。
  取能线圈与 Rogowski 测量线圈分开，不把空心测量线圈默认成充足电源。
- 与原候选的关系：补足 S4、S6 原先依赖电池的供电选择，
  不增加电流测量原理，也不单独测量电压。
- 来源归因：资源视角检查“可用能量”后，结合已知互感取能原理提出。
- 前提与限制：要求交流及足够的最小负载电流。
  低负载启动、过流保护、磁芯饱和和取能对测量的串扰均待核验。
  无法据此宣称装置始终自供电，稳定直流不能直接采用此机制。

### S9：旋转屏蔽片调制静电场，扩展 S1 到直流电压

- 资源到子目的：利用时间维度主动改变电容耦合，
  把原来不产生位移电流的恒定电压转换为可同步检测的交流信号。
- 具体机制：在地电位的拾取电极前加接地旋转屏蔽片，
  周期遮挡和暴露电极，使导线至电极的有效耦合电容成为 `C(t)`。
  在静态电压近似下，电极电流包含 `U dC/dt`，
  以转轴相位作参考同步解调，再依固定几何和调制幅度标定电压。
- 与 S1 的区别：保留电容传感，增加明确的机械调制和相位读出，
  不再要求被测电压自身随时间变化。
- 来源归因：时间资源视角触发，随后调用电场磨式传感的一般知识。
  原理知识为已知，当前结构对超高压场景的精度只是待核验候选。
- 前提与限制：电极和屏蔽片有稳定的地电位参考，几何固定。
  相邻导线、外壳畸变场、污染和旋转机构误差仍影响反演。
  与 S5 或 S6 组合才覆盖直流电流，不单独宣称完成两项测量。

## 增量判断与停止

本次补扫新增三项：S7 是复用已有结构的部署候选，
S8 是原电流方案的供电补充，S9 是电压转导链中新增主动调制的候选。
只有 S9 扩展了阶段一所列测量链对稳定直流的读出方式。
S7、S8 不应统计成新的完整双量测量方案。

没有改变原有精度、成本或交流/直流边界的结论。
回看六类资源均已区分题干直接给出、常识推断与新增引入，
三项增量均有具体操作和读出路径，未把待确认条件写成题干事实。
