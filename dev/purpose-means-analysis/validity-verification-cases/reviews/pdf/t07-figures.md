## 原图与原文直接给出的信息

### 题干及解答中的条件

物理页 39 的题干确为从飞机测量河深，每隔 300～500 m 一次，
全长 100 km，无特殊设备，不让人着陆，要求最便宜的测量，
精度 ±0.5 m，流速未知。
`±` 不是 OCR 的汉字“土”。

这些话确实出现在物理页 85 的解答重述中，后者还明确只允许支付飞行费用。
这属于原书两处表述的差别，不是 OCR 凭空添加。

### 图 3 的字母、线条及照片读数

图中字母按西里尔字母序列转写为 **А、Б、В、Г**。
扫描图的 А、В 分别与拉丁 A、B 同形，Г 与希腊大写 Γ 同形。
这里是字形辨识及序列转写，不声称可从位图恢复排版字符编码。
第二个浮标的字形清楚是 **Б**，不是 E。

- А、Б 是水面水平线上的两个小圆点，А 在左，Б 在其右。
- В 是下方带斜线填充边界上的汇合点，对应文字中的石块。
- 两条实斜线从 А、Б 分别连接到 В，对应两根钓丝。
- Г 标在水面线上，位于两个浮标右侧。
  Г 与 В 之间画有近竖直的虚线，对应原文所求的 ВГ。
  图中没有直角小方框，但作者把此虚线画作上下边界间的竖直深度线。
- А、Б **均在 Г 左侧**，即图 3 画的是两浮标处于石块垂直投影同一侧。
  这与图 2(b) 两上点分居下点水平位置两侧的画法不同。
- 图右侧另有一个水平向左的箭头，未写文字标签。
  它与流向示意相容，但原图没有因此给出流速或流场均匀性条件。
- 水面横线贯穿 А、Б、Г，并延伸到三点外，不能读成 АБ 间的刚性连杆。
  原文还明确说两个木块“并不相联”。

相邻文字明确写的是：已知 **АВ 和 БВ**，测定照片上的 **АБ**，
求出 **ВГ**。故已知量为两条斜绳边，照片读取的是两个水面浮标的间距。
照片读数与第一条绳边并非同一个量。
米尺固定在一个浮标上是文字给出的尺度来源，图 3 未画出米尺。

证据：[PDF 物理页 86](../../_private/references/altshuller/Altshuller-creativity-as-an-exact-science.pdf#page=86)、
[图 3 与读数文字局部图](../../_private/evidence/pdf-check/t07/page-86-figures-and-reading-300.png)。

### 绳长与“更深、间距更小”

物理页 85 原文确实规定两根钓丝长度一定要超过河水深度，
并说可通过投下试验验证。
原文也确实写“河水越深，木块А与Б的距离越小”。
后接括号跨页说明两个木块并不相联。
因此“距离越小”不是 OCR 将“大”错成“小”，也不是旧报告自行添加。

## 没有给出的条件

图 3 把两条绳画为直线，并在同一二维图中画出水面、河底及竖直虚线。
这足以确认作者意图使用竖直平面内的理想三角形几何，
不能再说作者图示意图完全不明。
但二维示意图本身不能证明投放后的装置必然处于该平面。

本次核查未发现刚性杆、横向导轨、浮标之间的连接、张紧机构，
也未发现让两浮标保持对置的结构。
文字和图均没有说明如何在任意未知流场中保证绳索张紧、足够笔直，
以及两个浮标与石块处于同一竖直平面。
图上的直线不能代替这些条件的现场成立性证明。
原文亦未给摄影误差、材料尺寸或 ±0.5 m 精度验证数据。

上述缺项判断仅限本轮读取的三页，不扩展为对发明证书或全书其他位置的断言。

## 与 OCR 及既有判断的差异

| 既有记录 | PDF 复核结果 | 影响 |
| --- | --- | --- |
| 木块 A、E，绳边 AB、EB | 西里尔 А、Б，绳边 АВ、БВ | 明确字母映射，修复 OCR 混淆 |
| “测定照片上的 AB”似与绳边 AB 重复 | 照片上为 АБ，绳边为 АВ | 消除可观测量符号歧义 |
| “木块A与的距离越小”有字缺失 | 第二木块为 Б，且原书确写“越小” | 补齐 OCR，保留原书原句 |
| 图 2、图 3 不可判读，无法核对构型 | 两图现已核对，图 3 是同侧构型 | 图缺失限制已消除 |
| 无法知道原图是否给进一步平面约束 | 图画了竖直虚线及二维理想构型，无约束机构 | 明确作者意图，仍未证明现场前提 |
| 原文未交代如何保持浮标位于投影两侧 | 图 3 本身没有采用两侧构型 | 应以同侧图示讨论原书单调句 |

旧 `comparison.md` 已区分两侧构型的两项之和与同侧构型的两项之差。
现在原图确证为同侧构型。
按旧报告使用的固定长度直绳、共竖直平面理想模型，
原书“更深、间距更小”的方向与图 3 同侧结构可能相反。
这里应记录为原书单调描述与其图示的局部不一致，
不能把它当成 OCR 错误，也不据此扩展为整个测量方案无效。
三边几何反演本身与这句定性单调描述是否写反是两项判断。

## 对结论的影响及未复核内容

**不改变 T07 的 B 类判断。**
原图确认了原书核心机制仍是两个水面浮标、同一沉底石块、
两条已知长度绳边及照片中的水面间距。
它没有使冻结候选补出第二浮标或水面间距反演，
本轮新增图示证据也不能回填到答案前记录。

需要调整的是证据精度和限制的措辞：

- “缺图、字母无法判断”已被本轮消除。
- 图示明确了作者预期的同侧、共竖直平面理想构型。
- 实际装置实现该平面、直绳和张紧条件的保证仍未给出。
- 原书单调关系句与图 3 同侧结构之间新增了具体可定位的疑点。
