# 局部行为验证夹具

这些是本次调研后编写的可复用验证材料，不是正式 Skill 的运行依赖。
部分脚本和证据被故意设置为有缺陷或不充分，用于观察 Skill 使用者是否识别假通过。
不要将夹具中的示范错误当作项目实现或直接用于真实验收。

读取 `requests.md`，使用 Skill 完成指定范围的核验。
允许在独立临时目录保存运行记录，不改动原始夹具或正式 Skill，
不启动其他子 agent，不递归执行整套收尾流程。
预期判定由主 agent 独立保存，评估者不接收答案或已怀疑的问题。

收录的实际核验结果见上一级 `trial-results.md`。
从仓库根目录重放夹具：

```bash
python3 dev/task-final-review-research-20261026/replay-trial.py
```

重放记录保存在打印出的新临时目录，脚本完成不等于夹具全部通过。
故意失败的目标及其意义在核验记录中说明。
