## 研究范围与充分性

七个子 agent 分别收集公开 Skill、真实仓库指令、平台工程实践、测试方法、
独立评判、内容研究、数据与操作。主 agent 补充跨路线、中文及反面经验检索。
共形成 61 组来源卡片，包含原始规则、实现、实际工作记录及研究，
不是 61 项独立实验，也不能据此推定本 Skill 的收益幅度。

所有正式卡片均读取了相关原文，部分来源只读与机制有关章节，已在报告标明。
动态网页和默认分支可能变化，能取得版本或 SHA 时已记录。
无法访问的页面、PDF 和旧路径单独记录，没有用搜索摘要补写事实。

第二轮补充检索仍主要出现新鲜证据、零测试、实际断言、工作范围与误报，
新发现是这些机制的具体实现或边界，不要求再改变按需组合的架构。
据来源类型覆盖和新增机制趋于重叠，结束本轮收集。
这表示本轮检索已达到可用于升级的覆盖，不表示穷尽整个互联网。
公开、可检索的中英文材料存在选择偏差，未执行外部工作流或复现论文实验。

## 总体策略

保留现有按任务选择检查的架构，直接改进已有规则及其操作例子。
将成本高、依赖领域前提的方法留在按需参考文档，不增加每项任务的强制步骤。
不安装工具，不新增运行时 hooks、外部依赖、评分系统或通用门禁框架。
方法转述采用独立表述，不复制外部 Skill 或提示词正文。

## 机制与决定

“补强”是把缺口融入已有规则；“条件采用”只在对应风险存在时使用。
“已覆盖”不再重复增加说明；“不整合”保留来源和不适配理由。

## 已覆盖机制的去重

真实执行、独立预期、正反样例、回归风险、原始来源、上下文隔离、
按材料分工、等待全部意见、批判采纳、失败分类、修后重验、授权边界，
已在基线中明确，不再以新名词新增平行阶段。
M01–M27 多为现有规则的可操作细化，不代表增加二十多个每次必做的检查。

## 验证安排

1. 核查文档结构、元数据、相对引用及改动范围。
2. 用故意包含空测试、失效证据和合法空结果的小型夹具作局部实际试用。
3. 让全新读者审阅执行清晰度；独立核验采纳记录与最终规则是否一致。
4. 根据反馈判断修订，只有重要变化才启动新一轮独立评审。

本轮尚未形成跨真实项目、跨模型的受控效果比较，不能宣称已证实整体质量提升幅度。
