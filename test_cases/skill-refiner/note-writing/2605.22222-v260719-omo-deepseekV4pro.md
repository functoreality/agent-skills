## 论文概要

ARC-STAR 提出一种针对冻结 PDE 基础模型（如 Poseidon、DPOT）的部署时后处理修正框架：全局修正器消除全场偏移 + 局部分块精化器（halo-read center-write）处理空间集中的残余误差 + 部署时用无真值标签的创新分数（innovation score）将有限计算预算路由到高风险区域。核心贡献是发现全局修正后的残余误差在空间上高度集中（基尼系数 0.48）并据此设计可审计的两阶段修正架构。

Hann 窗就是一个平滑的权重曲线，边缘为 0、越往中心越大（到中心为 1）。形状像一个倒扣的钟：

```
 1.0 ▁▂▄▆█████▆▄▂▁
 0.0 ████████████████
     边缘          中心          边缘
```

在 ARC-STAR 里的用法：L 对每个 16×16 块独立产出修正残差 δ_b。问题是相邻的块各自算各自的，边界处两个块的修正值可能不连续——拼起来就有一道缝。Hann 窗的解法就是把每个块的残差**乘以这个平滑权重**：边缘处权重趋近于 0（修正被压到几乎没有），中心处权重为 1（修正完全保留）。相邻块在接缝处两个都接近 0，叠加后过渡平滑，自然就不留伪影了。

"outer-product"是说 2D 窗口不是单独设计的，而是用一维 16 像素的 Hann 窗和自己的转置做外积：w_H = h × h^T，得到一个 16×16 的 2D 权重图。

- **G 已经把大部分活干了。** G 是全场修正，不嫌边界——它对每个像素都修。L 只处理 G 修完后残余的空间集中误差。如果某处残余恰好在边界上，L 修不了，但那个位置至少已经被 G 修过了。论文数据（G 单独降 91–99%）也说明大部分辛苦活不在 L 身上。
- **Hann 窗不是二值掩码，是渐变衰减。** 紧邻边界的第二圈像素权重虽然低（~0.04），但不为 0。离边界稍微往里两三个像素，权重就上来了。所以准确说"最外一圈完全修不了，再往里逐步能修"，不是整个交界区都修不了。

不过你说得对，这确实是一个理论上存在的盲区，论文没有讨论。值得在文献笔记里加一句：Hann 窗代价是每个块的边界一圈像素无法被 L 修正。
