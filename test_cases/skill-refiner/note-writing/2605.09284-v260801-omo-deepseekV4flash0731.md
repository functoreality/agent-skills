```diff
+  - 若新旧内容语义差异大（非局部措辞调整），先判断是否为"删除旧内容 + 新增新内容"两个独立改动，而非替换
+- 拆解完成后做完整性核对：对照 old/new 全文逐处检查，确认每个可见差异都被某个原子改动覆盖，无遗漏
+- 归因必须逐原子改动分别进行，一列列出"编号 → 归因"，不得在归因前先给出聚类结论
+  - 归因复杂时可另起行或缩进展开，不必压缩进一行
+  - 聚类（如需）只能在全部归因完成后进行，作为对已归因项的整理
+  - 大类下若存在明显不同的子目的，应分小类，每小类列出包含的改动编号，避免把异质点漏记
```
