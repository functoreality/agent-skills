# 目的手段链分析：空心锥体规格与内表面形状检验

分析约定：本次按替换性设计探索检验方案，各候选方向按工作原理展开。
以完成规定的检验功能为根本目的，重点寻找兼顾检出能力与作业效率的手段。
样板数量暂不作为必须保留的设计变量。
不同检验项目可组合使用不同观测方式，候选原理不代表已满足具体工件的检验要求。

题给示例规格：高 1000 mm，下底直径 700 mm，上底直径 400 mm，壁厚 30 mm。
直径对应内表面还是外表面、壁厚的定义及允许偏差尚未给出，
内表面名义尺寸与合格界限需据相应图样确定。
“增加样板”首先改变检查位置的覆盖程度，不直接等同于提高单次测量精度。

* 判定每件空心锥体的规格及内表面形状是否符合要求
	* 明确各检验项目的合格判据：暂缓（需明确名义几何、允许偏差及检验基准）
	* 获得足以支持合格判定的工件几何信息
		* 获得各检验项目的几何观测信息：方案空间，or
			* 通过接触工件获得几何观测信息：方案大类，or
				* 将工件与实体几何基准比较：方案大类
					* 提供对应待检几何的实体基准：方案空间，or
						* 以横截面轮廓构造实体基准：方案大类，暂缓（需展开不同轴向位置的轮廓适配方式，现有截面样板属于此方向）
						* 以轴向剖面轮廓构造实体基准：方案大类，暂缓（需展开沿高度的轮廓比较及周向覆盖方式）
						* 以完整内表面形状构造实体基准：方案大类，暂缓（需展开整体基准的装入及配合差异读出方式）
					* 使实体基准相对于工件处于规定的比较位置：暂缓（需按检具形态展开定位及可达性条件）
					* 获得工件与实体基准的配合差异：暂缓（需展开间隙、干涉及其可辨识方式）
				* 通过接触测头的位置获得表面几何信息：方案大类，暂缓（尚需展开测头定位与位置读出机制）
			* 通过非接触方式获得几何观测信息：见“单独分析：非接触几何观测”
		* 使观测范围覆盖规定的待检区域：方案空间，or
			* 以同时观测的区域覆盖规定的待检区域：方案大类，暂缓（需展开整体检具或多个观测单元的空间布置）
			* 以相对运动中各次观测区域的并集覆盖规定的待检区域：方案大类，暂缓（需展开运动轨迹、观测间隔及局部轮廓适配条件）
		* 使观测信息的误差满足判定要求：暂缓（待明确允许偏差后分析所需分辨能力与误差控制）
	* 依据合格判据形成检验结论：暂缓（待明确判据及检验信息的表达方式后展开）

# 单独分析：非接触几何观测

* 通过非接触方式获得几何观测信息：方案空间，or
	* 利用表面反射光获得几何信息：方案大类，or
		* 通过不同方向光路的三角几何关系确定表面位置：方案大类
			* 确定各光路的成像模型及相对位姿：暂缓（需按相机与投射器的配置展开几何标定）
			* 获得同一表面点在不同光路中的对应关系：or
				* 利用局部投射光迹的位置标识建立对应关系：方案大类，暂缓（需展开激光光斑或光条的识别，以及内表面照明与接收的共同可达性）
				* 利用投射图案的编码建立对应关系：方案大类，暂缓（需展开结构光编码的解码，以及金属表面反光和遮挡的处理）
				* 利用不同视角图像中的表面纹理匹配建立对应关系：方案大类，暂缓（需明确内表面是否具有可稳定匹配的纹理）
			* 由对应光路的几何交会求得表面点位置：暂缓（需按点、线或面观测形式展开求交及测量坐标表达）
		* 通过光脉冲的往返传播时间确定表面距离：方案大类，暂缓（需由允许偏差确定所需计时能力及多重回波区分条件）
		* 通过光的聚焦状态确定表面距离：方案大类，暂缓（可沿色散共焦等方向展开，需明确工作距离与量程）
	* 利用工件与传感器之间的近场电磁耦合获得几何信息：方案大类，暂缓（需展开间距反演及材料特性补偿，尚未选定具体原理）
	* 利用喷嘴与工件间隙对气流的影响获得几何信息：方案大类，暂缓（需展开气压或流量到间隙的标定关系及测头定位）
	* 利用空气中传播的声波回波获得几何信息：方案大类，暂缓（需展开回波时延到距离的换算及斜面回波接收条件）
	* 利用穿透工件的射线投影获得几何信息：方案大类，暂缓（需展开多角度重建与内外表面提取，设备空间及穿透能力尚不明确）

原理依据：三角测量由已知光路几何与成像位置确定距离，
编码结构光和表面纹理匹配提供不同的对应关系来源。
参见 [Micro-Epsilon 三角测量原理](https://www.micro-epsilon.com/wiki/laser-triangulation/?sLang=en)、
[Zivid 结构光与立体视觉说明](https://support.zivid.com/en/latest/camera/support/faq.html)。
点或线观测需结合主树中的覆盖手段获得区域信息，不能将一次局部观测视为完整内表面检验。

其他光学原理参见 [SICK 光脉冲飞行时间测量](https://www.sick.com/us/en/glossary/time-of-flight-measurement/g/p553647)、
[Micro-Epsilon 色散共焦原理](https://www.micro-epsilon.cn/service/glossar/Konfokal-chromatisch.html)。
声学候选指通过空气传播的回波测距，
参见 [Microchip 回波测距原理](https://onlinedocs.microchip.com/oxy/GUID-96D864E8-9F26-4895-9ABC-7ABC158C55B2-en-US-6/GUID-1B5F6CF1-3687-4BE8-8DAB-7B5CE6AB20A0.html)。

近场电磁、气动与射线方向的原理示例分别参见
[Micro-Epsilon 涡流位移测量](https://www.micro-epsilon.com/fileadmin/download/products/cat--eddyNCDT--en-us.pdf)、
[Mahr 气动量仪说明](https://metrology.mahr.com/en-int/gaging-tips/detail/pushing-the-limits-of-air-gaging/)、
[ZEISS CT 几何测量](https://www.zeiss.com/metrology/en/services/zeiss-measurement-services/ct-measuring-services.html)。
将这些原理用于题给锥体属于待细化的候选推演，尚未据此作精度、检验速度或适用设备的判断。
